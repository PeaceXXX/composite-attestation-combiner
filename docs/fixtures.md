# Fixtures

All data under `data/` is fictional and generated deterministically for this
demo (seed `20260928`). Nothing here is a real measurement, key, or device
identity.

## `data/reference-manifest.json`

Golden values the verifiers compare evidence against:

- `cpu.min_tcb_version`: minimum accepted TCB version (`2.0.0`)
- `cpu.allowed_tee_types`: `["tdx"]`
- `cpu.golden_mrtd` / `cpu.golden_rtmr`: 48-byte hex measurements
- `cpu.required_td_attributes`: bitmask — evidence must include all these bits
- `gpu.allowed_models`: `["H100", "H200"]`
- `gpu.min_driver_version`: `550.54.15`
- `gpu.golden_firmware`: per-model, per-component hex measurements
- `freshness_window_seconds`: `300`

## `data/samples/*.json`

| File | Scenario | Expected |
|---|---|---|
| `pass.json` | valid CPU + GPU evidence, bound to one session | GRANT |
| `tampered-cpu.json` | `rtmr3` replaced with random bytes | DENY (cpu) |
| `tampered-gpu.json` | `gsp` firmware measurement replaced | DENY (gpu) |
| `nonce-splice.json` | GPU report from a different session nonce | DENY (binding) |
| `stale.json` | valid evidence, backdated 1h by the demo CLI | DENY (freshness) |
| `cpu-only.json` | `uses_gpu: false`, no GPU evidence | GRANT (gpu skipped) |

`issued_at` ships as `0` (placeholder) in the JSON files; the demo CLI
normalizes it to "now" (`stale.json` → now − 1h). Use
`go run ./cmd/demo --print-request <name>` to emit a POST-ready request with
a fresh timestamp.

## Regenerating

The fixtures were generated by a short throwaway script (seeded PRNG);
there is no checked-in generator because the values are arbitrary. To
rotate them, replace the hex strings in `reference-manifest.json` and the
matching `pass.json` fields with any 48-byte (CPU) / 32-byte (firmware)
hex, then derive the tampered samples by mutating one field at a time.
